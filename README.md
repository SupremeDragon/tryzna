# ТРИЗНА

2D-RPG про сутність, що втратила світ і мусить пройти три світи, щоб його повернути —
або зрозуміти, що повертати його не варто.

**Рушій:** Godot 4.7 (GDScript) · **Платформа:** Windows (Steam) · **Стан:** M1 — сірий прототип

## Головна ідея одним абзацом

Три світи — це три жанри й три ракурси камери. У світі богів ти дивишся **згори**, бо
ти бог. У світі смертних — **три чверті збоку-згори**, бо ти всередині життя. У світі
мертвих — **строго збоку, площинно**, бо смерть забирає в тебе вимір: ти більше не
обираєш куди йти, тільки вперед або назад. Ракурс — не прийом, а стан душі персонажа.

## Як почати на іншому комп'ютері

```
git clone https://github.com/SupremeDragon/tryzna.git
cd tryzna
```

Що треба поставити:

| Що | Навіщо | Звідки |
|---|---|---|
| Godot 4.7 stable (win64) | сам рушій | `winget install GodotEngine.GodotEngine` |
| Python 3 + Pillow | скрипти в `tools/` ріжуть шари й малюють світло | `pip install pillow` |

Далі:

| Команда | Що робить |
|---|---|
| `tools\editor.bat` | відкрити проєкт у редакторі |
| `tools\run.bat` | запустити гру |
| `tools\test.bat` | прогнати димові перевірки (мають бути всі зелені) |
| `tools\shots.bat` | наробити знімків у `builds/shots/` |

Перший запуск довший: Godot імпортує текстури заново, бо `game/.godot/` навмисне
не в репозиторії — це кеш, він у кожного свій.

**Чого в репозиторії немає:** `art_src/raw/` — сирі генерації з Flow і локальної
моделі. Вони важкі, одноразові й лежать локально. Усе, що пройшло відбір, лежить
в `art_src/approved/` і в git є.
