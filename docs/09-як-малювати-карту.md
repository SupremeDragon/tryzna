# 09 — Як малювати карту

> Для Міші. Нічого малювати від руки не треба: усі плитки вже намальовані,
> ти їх тільки **розставляєш**. Це ближче до укладання плитки в кімнаті, ніж
> до малювання.

## Куди тицяти

1. У Godot відкрий **`scenes/plyn_map.tscn`** (панель «Файлова система» ліворуч
   унизу → тека `scenes` → подвійний клац на `plyn_map.tscn`).
2. У дереві сцени (панель «Сцена» ліворуч угорі) обери шар:
   - **«Земля»** — те, по чому ходять: трава, ґрунт, камінь, вода, пісок;
   - **«Предмети»** — те, що на ній стоїть: дерева, паркани, хати.
3. Щойно обраний шар — унизу зʼявляється вкладка **«TileMap»**. Там палітра
   плиток.
4. Тицяєш плитку в палітрі → клацаєш по полю. Тягнеш мишею — кладеться доріжка.

**Гарячі клавіші там же:** `D` — піпетка (взяти плитку, на яку вказуєш),
правий клац — стерти.

## Чому шарів два, а не один

«Предмети» мають увімкнене **сортування по Y**. Через це дерево, яке ближче до
глядача, само лягає поверх того, що далі. Якщо покласти дерево на шар «Земля»,
воно почне ховатися за сусідніми клітинками — це не помилка редактора, це
означає «ти поклав його не на той шар».

## Що де в наборі

Атлас — `art/plyn/atlas_terrain.png`, сітка 14 на 7. Рахунок від нуля,
перший рядок ліворуч угорі.

| рядок | що там |
|---|---|
| 0 | трава (0–3), ґрунт (4–5), камінь (6–7), вода (8–10), пісок (11–13) |
| 1 | те саме, інші варіанти |
| 2 | трава з кущем, ґрунт, камінь, пісок-берег, вода з течією |
| 3 | дерево, камінь на траві, паркани, брила, дахи брунатні |
| 4 | дерева, кущ, паркани, пісок із камінням, дахи червоні |
| 5 | дерева, паркани, камінь із водою, дахи сині, хата темна |
| 6 | трава з камінням, пісок, персонажі, скрині, зілля |

## Якщо плитки лягають криво

Числа сітки задані в `game/tools/build_tileset.gd`:

- `DIAMOND` — розмір самого **ромба** (168 на 84). Не розмір картинки.
- `LIFT` — на скільки картинка піднята над клітинкою (26). Менше — плитки
  тонуть у землю, більше — висять над нею.

Після зміни треба перезібрати набір:

```
Godot --headless --path game --script res://tools/build_tileset.gd
```

## Звідки взявся атлас

Аркуші, які дав Міша, **згенеровані**, а не намальовані по сітці: крок у них
дробовий і різний по осях (191.85 на 188.50). Godot такого не вміє, тому аркуш
перескладається в чистий атлас із рівним кроком 192:

```
python tools/build_atlas.py art_src/tilesets/RPG_2.5D_tile_set_2K_202609051118.jpeg \
    game/art/plyn/atlas_terrain.png --step 191.85 188.50 --origin 62 30 \
    --cols 14 --rows 8 --first-row 1 --tolerance 40
```

Числа сітки для будь-якого аркуша знаходить `tools/grid_probe.py`.
